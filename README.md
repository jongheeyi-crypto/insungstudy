# Paw patrol · 출동! 인성 대원의 미션 대작전 🐾

5살 인성이의 하루 공부 미션을 체크하고, 다 모으면 **발자국 스티커**를 받는 칭찬 스티커판 웹페이지입니다.
퍼피구조대(PAW Patrol) 감성의 구조대 테마로 만들었지만, **공식 로고·캐릭터 이미지는 쓰지 않았습니다.**
방패 배지, 발자국, 구조대 강아지는 모두 이 저장소에서 직접 그린 SVG입니다.

## 어떻게 쓰나요?

1. 사이트를 열면 오늘의 미션 5개가 보여요. (원리셈 · 소마셈 · 소마도형 · 잉글라이더 숙제 · 원서 3권)
2. 미션을 하면 카드를 톡 눌러 체크해요. `원서 3권`은 1·2·3 동그라미를 하나씩 눌러도 되고, 카드를 누르면 한 번에 체크돼요.
3. **5개를 모두 체크하면 `🐾 발자국 스티커 받기!` 버튼이 반짝이며 켜져요.** 누르면 발자국이 30칸 판에 `쾅!` 하고 찍혀요. **도장은 하루에 딱 1번**이고, 이미 찍은 날은 버튼이 `🐾 오늘 도장 완료!` 로 잠겨요(눌러도 1일 1회라고 알려 줘요). 찍힌 발자국에는 `11/16` 처럼 **찍은 날짜가 흰색 알약 배지로 발자국 위에** 표시돼요.
4. 30칸을 다 채우면 축하 폭죽과 함께 **🎉 30개 대성공!** 창이 떠요. `상품 받았어요! 새 스티커판 시작하기`를 누르면 달성한 판 수가 `🏆` 배지로 쌓이고 새 판이 시작돼요.
5. 목표 상품은 처음에 **`다이소 가서 원하는 거 고르기`** 로 되어 있고, `⚙️ 엄마 설정`에서 언제든 바꿀 수 있어요.

### ⚙️ 엄마 설정

`⚙️ 엄마 설정` 은 **어른 확인(한 자리 + 한 자리 덧셈)** 을 통과해야 열려요. 아이가 들어가서 `+1 보충`이나 초기화를 마구 누르지 못하게 한 잠금이에요.

- 🎁 상품 이름 수정
- 📋 미션 추가 · 이름/이모지 수정 · 삭제 · 기본 5개로 복원
- 🐾 스티커 `+1` 보충(빠진 날) / `−1` 취소(실수로 찍었을 때) / 오늘 미션 체크 초기화
- 🔄 **전체 초기화 (0부터 다시)** : 한 번 누르면 "한 번 더 누르면 0개로 초기화돼요" 로 바뀌고, **두 번째로 눌러야** 스티커판 · 오늘 미션 체크 · 달성한 판 기록이 0이 돼요. 상품 이름과 미션 목록은 그대로 남아요.
- 💾 백업 JSON 내보내기 · 복사 · 가져오기

## 스티커판을 초기화하는 링크 (한 번만 동작)

브라우저 주소 뒤에 `?reset=토큰` 을 붙여 열면 그 브라우저의 기록이 **딱 한 번** 초기화돼요.

```
https://jongheeyi-crypto.github.io/insungstudy/?reset=20261116-1
```

- 아직 쓰지 않은 토큰일 때만 `스티커판 · 오늘 미션 체크 · 달성한 판 기록`을 0으로 지우고, 상품 이름·미션 목록은 그대로 둡니다.
- 처리한 토큰은 `localStorage` 의 `insungstudy.resets` 에 남겨서, **같은 링크를 나중에 다시 열어도 새로 찍은 스티커를 지우지 않아요** ("이미 초기화한 링크예요" 안내만 나옵니다).
- 주소창의 `reset` 값은 처리 직후 자동으로 지워져요. 새로 초기화하려면 토큰만 바꿔서(예: `reset=20261201-1`) 열면 돼요.

## 저장 방식

- 서버가 없고, 모든 기록은 **그 브라우저의 `localStorage`에만** 저장돼요. 무료 GitHub Pages로 동작합니다.
- 브라우저 기록/사이트 데이터를 지우면 스티커도 사라져요. 기기를 바꾸거나 기록을 지우기 전에는 `⚙️ 엄마 설정 → 내보내기`로 백업해 두세요.
- 검색 노출을 막으려고 `<meta name="robots" content="noindex, nofollow" />` 를 넣었습니다. 아이 이름만 쓰고, 연락처·주소 같은 개인정보는 넣지 않았어요.

## GitHub Pages 켜기 (처음 한 번)

저장소 → **Settings → Pages** → *Build and deployment* 에서
**Source: Deploy from a branch**, **Branch: `main` / `(root)`** 로 저장하면
`https://jongheeyi-crypto.github.io/insungstudy/` 주소로 열립니다.
휴대폰 브라우저에서 열고 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있어요.
